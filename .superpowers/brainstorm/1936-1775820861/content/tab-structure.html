Character Sheet Tab Structure

The old sheet had 11 tabs. How should we organize the rebuild?

A

Consolidated (6 tabs)

Summary — portrait, abilities, defenses, health, shields, conditions
Skills — full skill list with training, focus, bonuses
Inventory — equipment, weapons, armor, credits, weight
Features — feats, talents, traits, class features, Force powers/secrets/techniques
Details — biography, description, class progression, affiliations, languages
Settings — ability generation, NPC toggle, modes/effects

Pros

  • Less clicking between tabs
  • Modern feel
  • Easier to find things

Cons

  • Some tabs get dense
  • Force content mixed with feats
B

Moderate (8 tabs)

Summary — portrait, abilities, defenses, health, shields
Skills — full skill list
Inventory — equipment, weapons, armor, credits
Feats & Talents — feats and talents
The Force — powers, secrets, techniques, regimens (conditional)
Traits & Languages — traits, affiliations, languages, beast tab
Details — biography, class progression
Settings — ability gen, modes, effects

Pros

  • Force content gets its own space
  • Balanced density

Cons

  • More tabs than Option A
C

Keep All (11 tabs, like old sheet)

Summary, Class, Beast, Equipment, Feats & Talents, The Force, Affiliations & Languages, Traits, Modes, Changes, Settings, Notes

Pros

  • Familiar to existing users
  • Each section has breathing room

Cons

  • Many tabs for some characters
  • Some tabs very thin content
